# Map History Video — project template

Animated map explainer videos, made with code: Remotion renders the video, Kokoro (free, local,
Apache-2.0) reads the narration, NASA Blue Marble (public domain) provides satellite maps and
Wikimedia Commons provides free-licence photos.

Quick start:
    sh scripts/setup.sh                                   # once
    npx remotion render HistoryVideo out/demo.mp4         # renders the demo episode
    npm run studio                                        # live preview in the browser

Put your channel name in src/brand.json. A full worked example lives in examples/ (Haiti vs the
Dominican Republic: script generator, Shorts generator and the photo list for commons_fetch.py).

The step-by-step workflow (research → script → photos → voice → maps → render → thumbnail →
Shorts → upload text) is described in the skill's SKILL.md and references/.
